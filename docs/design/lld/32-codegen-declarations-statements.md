# LLD: Codegen -- declarations, statements, coverage

This reference documents three files of the Nova LLVM backend (`src/backend/codegen/`) that between them turn the type-checked AST into an LLVM module: `declarations.zig` drives the whole module-emit pipeline (extern declarations, string globals, function signatures, function bodies, the optimiser emit-path hook, coroutine prologue/epilogue, and object emission including the T6 per-file split), `statements.zig` lowers every statement kind (with the scope-end ARC release and defer/errdefer ordering that make Nova memory-safe without a GC), and `coverage.zig` is a small registry that records source blocks and writes the coverage metadata file. All three are Zig 0.16 and speak to LLVM through the `llvm` bindings package (`core`, `types`, `analysis`, `transform`, `target_machine`, `errors`). The heavy lifting for expressions, ARC helpers, destructors, and type resolution lives in sibling files (`expressions.zig`, `arc.zig`, `types.zig`, `llvm_codegen.zig`); the two big files here are the "skeleton" (declarations) and the "control-flow flesh" (statements) around those helpers.

A note on scope. Despite the name, `declarations.zig` does not contain standalone `emitStruct` / `emitVtable` / `emitEnum` routines. Struct layout, vtable construction (slot 0 = destructor), trait fat-pointers, and enum tag/payload layout are computed on demand by helpers in `types.zig`, `arc.zig`, and `expressions.zig` (for example `getOrCreateDestructor`, `constructTraitObject`, `getTypeSize`) and are referenced from here rather than defined here. What `declarations.zig` owns is the orchestration: it registers enums and traits into the compiler's lookup maps, builds every function signature under the flat "val_type word" ABI, wires the coroutine ABI for `async` functions, and runs the LLVM verify + optimise + object-emit tail.

## `src/backend/codegen/declarations.zig` (1633 lines)

**Role in the pipeline.** `compile(...)` is the single entry point the driver (`main.zig` / `pipeline.zig`) calls to lower a whole `ast.Program` to one or more object files. It constructs an `LlvmCompiler`, seeds it with the shadow typed-IR from sema (`sema_shadow.live_ir` / `live_store`), then proceeds in strict phases: (1) register const/enum/trait declarations into compiler maps; (2) collect all functions (including monomorphised instantiations and closures) via `collectFunctions` + `collectClosuresFromBlock`; (3) collect string literals and materialise them as immortal LLVM string globals; (4) declare all runtime/intrinsic externs (a long, target-split block), including FFI externs; (5) build the per-function local-type and local-type-id maps (the parameter/local `[]const u8` type-name and `TypeId` tables); (6) de-duplicate functions by name; (7) declare every function's LLVM signature; (8) reorder so erased-generic fallbacks come last; (9) compile every function body (with the emit-path hook and coroutine prologue/epilogue); (10) finish coverage; (11) emit the object(s).

**The function-signature ABI.** Nova uses a uniform "everything is one machine word" ABI. `compiler.val_type` is the word (i64 on native). In the signature-declaration loop every parameter type defaults to `val_type` (`@memset(params, compiler.val_type)`); the only exceptions are array-typed params, which flow as `ptr_type` so LLVM keeps pointer provenance and can vectorise (looked up from `function_local_types` by the `[` in the type name), and there is no sret: aggregates are passed and returned as the i64 word (a heap address) rather than by hidden pointer. The return type is chosen as: `val_type` for `main` (its `__nova_main` returns an int), `val_type` for a native `async` function (it returns the coroutine handle as a word), `void_type` for a `void` function, else `val_type`. `main` is emitted under the real symbol `__nova_main`; a native `async` function additionally gets the `presplitcoroutine` enum attribute and is recorded in `async_fns` so the later CoroSplit pass fires. `FunctionInfo` (defined in `llvm_codegen.zig`) is the per-function descriptor consumed throughout: `name`, `param_count`, `param_names`, `return_type` (a string), optional `ret_type_ref`, `body`, declared `params`, `is_async`, `instantiation` / `instantiation_id` (the monomorphisation key), `erased_generic`, and `source_file` (used by the T6 split).

**The emit-path hook.** Immediately after positioning the builder at a function's `entry` block, the body loop calls `if (lir_emit.emit_enabled and lir_emit.tryEmit(&compiler, fn_val, func)) continue;`. When the environment enables `NOVA_OPT_EMIT` and `tryEmit` proves it can lower this function's body from the optimiser IR (its provable subset), the optimised body is emitted and the AST body is skipped for this function. `tryEmit` fails closed: it returns `false` for anything it cannot prove, and the normal AST body-emit below runs unchanged. This is a per-function fallback, not a whole-module switch.

**Coroutine ABI.** For a native `async` function, `emitCoroPrologue` builds the LLVM coroutine intrinsic dance (`llvm.coro.id` / `size` / `begin`, a `nova_coro_alloc`ed frame, the initial `llvm.coro.suspend` switch into the body block) and returns a `CoroCtx`; `emitCoroEpilogue` builds the final-suspend, cleanup (`llvm.coro.free` + `nova_coro_free`), and end blocks. The promise slot carries the return value and a waiter word.

### Module-level state / constants

- `ffiCType` is the only module-private helper apart from the coro helpers; there is no module-level mutable state. All state lives on the `LlvmCompiler` instance created inside `compile`.
- `CoroCtx` (private struct): the handle/id/promise plus the four coroutine basic blocks (`final_bb`, `cleanup_bb`, `suspend_bb`, and the body is entered before returning). Fields: `hdl`, `id`, `promise`, `final_bb`, `cleanup_bb`, `suspend_bb`.

### Functions (source order)

- **`fn ffiCType(compiler: *LlvmCompiler, type_name: []const u8) types.LLVMTypeRef`** (private). Maps a Nova FFI scalar type name to its C-ABI LLVM type: `int`→i32, `long`→i64, `bool`→i8, `void`→void, everything else→`ptr_type`. Pure, no IR built. Used only when declaring `extern_lib` functions so they match the real C signature rather than the flat i64 ABI.

- **`pub fn compile(allocator, program, is_wasm, is_release, target_triple_opt, output_path, coverage_enabled, t6_split, objs_out, cache_dir, io) !void`** (pub; the module driver). The whole lowering pipeline. Non-obvious params: `t6_split` requests per-file object splitting; `objs_out` is an out-list the split path appends object paths to (ownership: paths are allocPrint'd with `allocator` and handed to the caller); `cache_dir` enables content-hash object caching in the split path; `io` is the `std.Io` used for filesystem access checks. Key steps and side effects:
  - Creates the `LlvmCompiler` (`LlvmCompiler.new`), sets `typed_ir` / `type_store` / `f2_types` from the sema shadow, `defer compiler.deinit()`.
  - Registers declarations into compiler maps: consts into `constants`, enums into `enums` keyed by `scopedStructName(e.name, file)` (module-scoped so two same-named enums in different modules do not collide, the S3 fix), traits into `traits` keyed by bare name.
  - `collectFunctions(program)` then, per collected function, sets the `current_collecting_*` context (name, instantiation, instantiation_id derived identically to the body-compile lookup, erased_generic) and runs `collectClosuresFromBlock` so lambdas are discovered with the right monomorphisation context.
  - If `t6_split`, prints a per-source-file function partition (`[T6]` diagnostics), grouping `functions` by `source_file`.
  - Collects string literals (`collectStringLiterals` + per-function `collectStringsFromBlock`), computes `heap_start` (16-byte aligned, min 1024), and adds the `heap_ptr`, `persistent_ptr`, and `free_list` globals. On wasm the heap pointers start at 0 and `__heap_base` is external; native starts them at `heap_start` and `heap_start + 32MiB`.
  - Materialises each string literal as an internal-linkage `{i32 refcount, i32 len, [N x i8] chars}` global with a **negative refcount** (`-1000000000`) so `nova_retain`/`nova_release` are no-ops on it (immortal constant). The comment is emphatic that this must match `getOrCreateStringLiteral` in `llvm_codegen.zig`, and that the old `+100000000` scheme drifted to zero and double-freed on hot literals. Globals recorded in `string_globals`.
  - Declares a large fixed set of runtime externs into `func_map`: numeric/string conversion (`nova_i64_to_string`, `nova_f64_to_string`, `nova_ieee_le_to_str`, `nova_f64_bits`, `nova_pg_be_f64`/`_i64`, `nova_html_find_meta`, `nova_f64_sqrt` = the `llvm.sqrt.f64` intrinsic, `nova_bool_to_string`), decimal128 (`nova_decimal_*`), and, native-only, closure invokers (`nova_invoke_str_closure`/`_void_closure`). WASM branch declares host imports (`log`, `nova_time_now`, `nova_get_stacktrace`, the test-harness imports, `nova_arg_count`/`_at`) tagged with `wasm-import-module`/`wasm-import-name`. Native branch declares `printf`/`puts`/`malloc`, logging, timers, the coroutine support (`setupCoroutineSupport`), process spawn/io/wait/kill, fs watcher, channels, mutex/condvar/rwlock/spinlock, the reactor API (`nova_reactor_*`, `nova_run_reactors`, timers, wake/post/drain), `nova_getrandom`, and crucially `nova_retain` (word→void) and `nova_release` (word + dtor ptr → void). Comments record what was retired: wolfSSL/wolfCrypt TLS, `nova_getenv`/`setenv`, file/dir shims, gzip -- all now pure Nova.
  - FFI: native-only, declares `nova_ffi_to_cstr`/`from_cstr`/`free_cstr`, then walks `program.declarations` for `fn_decl`s with a non-null `extern_lib`, records them in `ffi_externs`, and declares each with a true C signature built from `ffiCType` (params default to i64 when untyped).
  - Per-function local-type table build (first big loop over `compiler.functions`): allocates a `StringHashMap([]const u8)` (`local_types`) and a `StringHashMap(TypeId)` (`local_type_ids`) per function, sets `current_*` context (function name, instantiation, instantiation_id via `live_inst_ids` fallback, struct name via instantiation base name or the `Name_method` underscore convention with `isStructType`), then matches the function against `program.declarations` (free fn by symbol name incl. struct/module prefix; struct method by `methodSymbol(owner, name)` including the `__`-suffixed spec case; enum method by `Enum_method`) to record each parameter's type name (`typeRefToString`) and `TypeId` (`tidForTypeRef`, which PRESERVES optionality so a value-optional parameter is recognised as a boxed slot -- the C10 uniform boxed value-optional param ABI). Lambda functions (`__lambda_` prefix) get their module prefix from `lambda_parents` and their param types from `lambda_param_types` (with `__env` typed as `ptr`). Finally `collectLocalVarTypes` fills in body locals; both maps are stored in `function_local_types` / `function_local_type_ids` keyed by function name.
  - De-dup: a `seen` set compacts `functions` in place so each name is declared once.
  - Signature-declaration loop (see the ABI paragraph above): builds each `LLVMFunctionType`, adds the function, records it in `func_map`, and tags native async functions with `presplitcoroutine` + `async_fns`.
  - Reorder: rebuilds `functions` so all non-erased functions come first and erased-generic fallbacks last (so a real instantiation is emitted before its erased sibling can be skipped).
  - Body-emit loop (the largest block): for each function, skips a use-less erased fallback UNLESS it is `RawBuffer_` backing (M-10: the universal container backing must always be emitted or an erased container body links against an undefined `RawBuffer_init`); sets erased fallbacks to internal linkage (unless `t6_split`); rebinds all `current_*` context and re-matches the declaration for the module prefix; clears `locals`; appends the `entry` block; **runs the emit-path hook** (`lir_emit.tryEmit`, `continue` on success); frees and clears `current_saved_captures`; allocas every parameter (or reuses a `captured_globals` global, saving a backup for restore) and stores the coerced argument; allocas and zero-inits every body local (zero chosen per slot kind: `0.0` for double, `0` for int, `zeroinitializer`/null for ptr/vector to avoid an invalid `i0 0`); for `main` (native) mallocs the 16MiB heap and stores it into `heap_ptr`; resets the async promise/bb fields, runs `emitCoroPrologue` for async; pushes a root `Scope`; compiles each body statement via `compileStatement`; then, if the block did not already terminate, pops the root scope, runs its deferred statements in reverse, calls `releaseLocalVariables`, and emits the terminator (coro final-branch for async, `ret 0` for main, load-and-return-self for `_new`/`_init` constructors, `ret void`/`ret 0` otherwise); runs `emitCoroEpilogue` for async; deinits any remaining scopes and clears context.
  - Coverage finish: if enabled, writes the metadata file (`reg.writeMetadataFile`), declares the external `__nova_cov_counters` global and, in `main`'s entry block, inserts a `nova_coverage_init(N)` call.
  - Emit: if `t6_split and !is_wasm and objs_out != null`, delegates to `compileSplitEmit` and returns; otherwise `emitModule` writes a single object (`__nova_test.ll` dump name).
  - Errors: propagates allocation errors, `error.VariableNotFound` from lookups is not raised here (that is statements), LLVM verify/emit errors bubble from `emitModule`.

- **`fn compileSplitEmit(compiler, allocator, output_path, is_release, objs, cache_dir, io) !void`** (private; T6 per-file object split). Emits one object per source file so unchanged files can be cached. Marks `heap_ptr` and `_vtable_*` globals `LinkOnceODR` (they will appear in every clone and must merge at link). Builds `all_syms` (every function's mangled symbol) and `file_syms` (symbol set per source file). For each file: clones the whole module, then in the clone deletes the basic blocks of every function that belongs to a DIFFERENT file (leaving a declaration), so only this file's functions have bodies. With `cache_dir`: runs `globaldce`, prints the clone's IR to a string, hashes it (Wyhash, seeded by release flag) into a `nova_split_<hash>.o` path, and either records a cache hit (file already exists, via `std.Io.Dir.access`) or emits it (`emitModule`) as a miss; appends the path to `objs`. Without `cache_dir`: emits `<output>.<idx>.o` unconditionally. Prints `[T6]` hit/miss stats. Side effects: object files on disk, `objs` grows with allocator-owned paths (caller frees).

- **`fn emitModule(compiler, allocator, module, obj_path, is_wasm, is_release, dump_ll_name) !void`** (private; verify → optimise → object). Runs `elideBorrowedArc` (the NOVA_ARC_ELIDE prototype that removes provably-redundant borrowed retain/release pairs); optionally dumps the IR to `dump_ll_name`; runs `LLVMVerifyModule` (returns `error.LLVMVerificationError` on failure, printing the message); sets every `__destruct_*` function to internal linkage; native-only runs the pass pipeline (`default<O3>,globaldce` in release with loop/SLP vectorisation + unrolling enabled, else `default<O0>,globaldce`), then, if `arc.asan_codegen_enabled` (NOVA_ASAN_CODEGEN), tags every defined function with `sanitize_address` and runs the `asan` module pass AFTER the main pipeline (post CoroSplit); finally emits the object with `LLVMTargetMachineEmitToFile` (returns `error.LLVMEmitFileError` on failure). Errors: verify/pass/emit failures each return a distinct error after printing.

- **`fn declareCoroIntrinsic(compiler, name, overload) !void`** (private). Looks up an LLVM intrinsic by name and adds its declaration (overloaded on `overload` type when given, e.g. `llvm.coro.size` on i64), recording it in `func_map` under the intrinsic name.

- **`fn emitCoroPrologue(compiler, fn_val) !CoroCtx`** (private). Builds the coroutine entry: allocas the promise (`coroPromiseType`), zeroes the waiter slot, calls `llvm.coro.id` (passing the promise), `llvm.coro.size`, `nova_coro_alloc` (heap frame), `llvm.coro.begin` (handle); appends `coro.body`/`coro.final`/`coro.cleanup`/`coro.ret` blocks; emits the initial `llvm.coro.suspend` with a switch (default → suspend/ret, case 0 → body, case 1 → cleanup); positions the builder in `coro.body` and returns the `CoroCtx`. IR built; no tables mutated beyond the builder position.

- **`fn emitCoroEpilogue(compiler, fn_val, ctx) void`** (private). Builds the final-suspend switch in `coro.final` (case 0 → an `unreachable` trap block, case 1 → cleanup), the cleanup block (`llvm.coro.free` + `nova_coro_free`, branch to suspend), and the suspend/ret block (`llvm.coro.end`, then `ret` of the coroutine handle as an i64 word). Pure IR; the async function returns the handle.

- **`fn setupCoroutineSupport(compiler) !void`** (private). Declares all coroutine intrinsics (`llvm.coro.id/size/begin/suspend/end/free/resume/destroy/done/promise`) and the runtime coroutine/scheduler/async-io ABI: `nova_coro_alloc`/`_free`/`_release`, `nova_sched_schedule`(`_detached`)/`_next`, `nova_run`/`nova_run_root`, `nova_await_timer`/`_future`, `nova_register_waiter`, the async channel ops (`nova_chan_new`/`_send`/`_recv`/`_free`), async socket ops (`nova_io_recv_async`/`_accept_async`/`_take_result`, `nova_aserver_listen`(`_addr`), `nova_aaccept`/`nova_aconnect`/`nova_arecv`(`_deadline`)/`nova_asend`/`nova_aclose`), `nova_coro_hold_arg`, and the `when_all`/`selectAny` combinators (`nova_when_any`(`_deadline`)). All recorded in `func_map`.

**Gotchas / invariants.**
- The `instantiation_id` MUST be derived identically at collect time and body-compile time (raw id else `live_inst_ids.get(inst)`), or a closure's registration key and its lookup key diverge (comment at the derivation sites).
- Struct-name inference by the `Name_method` underscore convention is a fallback used when there is no explicit `instantiation`; it depends on `isStructType`.
- String-literal refcount must be the negative immortal sentinel and must match the other literal emitter; a positive-decrementing scheme is a latent double-free.
- Array params intentionally have NO `noalias` (unsound if the same array is passed twice); LLVM vectorises via a runtime overlap check instead.
- The erased-generic ordering + no-use skip is load-bearing: `RawBuffer_` is the sole exception and must be emitted unconditionally.

## `src/backend/codegen/statements.zig` (849 lines)

**Role in the pipeline.** `compileStatement` is a big `switch` over `ast.Statement` that emits one statement into the current basic block. Everything routes value production out to `compileExpression` (in `expressions.zig`); this file owns control-flow block wiring, temporary draining, and, most importantly, the ARC discipline: which locals are registered as owned for scope-end release, when a retain is inserted on assignment/return, and the exact ordering of `defer`/`errdefer`.

**Scope-end releases and defer/errdefer ordering.** Scopes are a stack (`self.scopes`) of `Scope { deferred_statements, errdeferred_statements, owned_locals }`. A `let` of an owned local (or a value struct with owned fields) appends an `OwnedLocal {name, type_name}` to the current scope's `owned_locals`. When a `.block` finishes normally, it runs the block's `deferred_statements` in REVERSE (innermost defer last-registered runs first), then releases the block's `owned_locals` in REVERSE (release in reverse declaration order), then removes those names from `current_local_types` and deinits the scope lists. `errdefer` is separate: `runErrdefers` walks the whole scope stack from innermost to outermost and, within each scope, runs `errdeferred_statements` in reverse -- and it fires ONLY on the error path (from the `return` handler when an error-union error arm is being returned). `return` itself runs every scope's `deferred_statements` (all scopes, innermost to outermost, reverse within each) and then `releaseLocalVariables()` before building the actual `ret`. Loop exits (`break`/`continue`) call `releaseScopesForLoopExit`, which releases owned locals of every scope INSIDE the loop (down to `current_loop_scope_depth`) so a mid-loop exit does not leak per-iteration locals.

**Per-statement summary.** `let` handles owned-local registration, tuple destructure (retain each owned element), trait widening (`constructTraitObject` when the declared type is a trait and the RHS is a known struct, plus a release of the original if it was owned), `any` boxing (`coerceToAny`), owned-retain on an r-value variable RHS, value-optional boxing (`buildValoptBox`), and M-1 copy-on-assign for value structs from a borrow (`buildValueStructCopy` + retain owned fields). `expr_stmt` either renders a JSX element directly into the current string builder, appends the expression's value to the current string builder, or (as a bare statement) releases the result of an owned call/struct-init. `if`/`while`/`for`/`switch` build the usual condition/body/merge blocks and, for loops, save/restore the break/continue targets and loop-scope depth. `return` builds the return value with all the ABI wrapping (value-optional box, trait widening, error-union wrap), runs defers, releases locals, and emits the coroutine store-and-branch, `main` int-return, or plain `ret`. `defer` just appends to the current scope's deferred or errdeferred list. `break`/`continue` release loop scopes then branch.

### Module-level state / constants

None. All state is on `LlvmCompiler` (`self.scopes`, `self.locals`, `self.current_*`, `self.pending_temps`, etc.). `Scope` and `FunctionInfo` are imported from `llvm_codegen.zig`; `getStructBaseName` from `types.zig`.

### Functions (source order)

- **`pub fn runErrdefers(self: *LlvmCompiler) anyerror!void`** (pub; method-style on `LlvmCompiler`). Walks the scope stack from innermost (top) to outermost, and within each scope runs `errdeferred_statements` in reverse registration order via `compileExpression`. Called only on the error-return path (from the error-union arm of `return`). Side effects: emits the errdefer expressions' IR. Invariant: error-path only, reverse within scope, innermost first.

- **`fn releaseScopesForLoopExit(self: *LlvmCompiler) anyerror!void`** (private). If a loop is active (`current_loop_scope_depth` set), releases the owned locals of every scope strictly above that depth, in reverse within each scope, via `releaseLocalByName`. Used by `break`/`continue` so per-iteration owned locals are freed before jumping out. Does NOT pop the scopes (the block handler still owns pop/deinit); it only emits the releases.

- **`pub fn compileStatement(self: *LlvmCompiler, stmt: ast.Statement, func: FunctionInfo) anyerror!void`** (pub; the statement dispatcher). Early-returns if the current block is already terminated (`LLVMGetBasicBlockTerminator` non-null) so dead code after a `return`/`break` is not emitted. Marks `pending_temps` and `defer self.drainTemporaries(temp_mark)` so temporaries created by this statement are released at statement end. If coverage is enabled and the statement is not a bare block, extracts the statement span, skips std-library and `test_harness.nova` spans, and registers + increments a coverage block (`cov_registry.registerBlock` + `compileCoverageIncrement`). Then a big `switch (stmt)`:

  - **`.let_stmt`**: First, owned-local registration -- for each declared name (single or destructure), if `isOwnedLocal(name, type)` OR it is a value struct with owned fields (`isValueStructName` + `valueStructHasOwnedFields`, which needs a scope-end `dropValueStruct`, not `nova_release`), append an `OwnedLocal` to the top scope. Then, if there is an initialiser, compile it. Destructure path: for each name, compute the tuple element address (`base + idx*8`, load the word), retain if the target is owned, coerce to slot type, store into the name's alloca. Single-name path: (a) trait widening -- if the declared type is a trait and the RHS resolves to a known struct (checked by BASE name so `Cell<int>` widens, the B5 SEGV fix), build a trait fat-pointer via `constructTraitObject`, mark the temp consumed, and release the original struct if it was owned (`getOrCreateDestructorPreferId`); (b) `any` widening -- box the value into a `{payload,dtor}` carrier via `coerceToAny` (unless already an `any` expr), consuming the temp; (c) owned-retain -- if the local is owned and the RHS is a plain r-variable (`.ident`/`.field_access`/`.index`, excluding an enum-variant constructor), retain; (d) value-optional boxing -- if the slot's `TypeId` is a value-optional inner and the RHS is not `undefined` and does not already yield a valopt box, `buildValoptBox`; (e) M-1 copy-on-assign -- if the declared type is a value struct and the RHS is a `.ident` or a borrow (`returnIsBorrow`), copy the bytes (`buildValueStructCopy`) into the local's own storage and retain the copy's owned (reference) fields, so `b = a` does not alias `a`. The comment is explicit that `returnIsBorrow` answers FALSE for `.ident` and is therefore the wrong predicate alone -- `.ident` is exactly the copy case. Finally coerce to the alloca's slot type and store. Errors: `error.VariableNotFound` if a name has no alloca.

  - **`.expr_stmt`**: If a current string builder is active and the expr is a JSX element, emit it directly into the builder (`emitJsxInto` + `jsxFlushLiteral`) and return -- single-buffer render, no per-element intermediate string. Otherwise compile the expr (or `buildGo` for a `go_expr`). If a string builder is active and this is not an assignment, append the value (`compileAppendToStringBuilder`). If no string builder: if the expr is owned and is a `call` or `struct_init`, consume the temp and release it (`getOrCreateDestructorPreferId` + `compileRelease`) so a discarded owned result is freed.

  - **`.block`**: Pushes a fresh `Scope`, compiles each statement (stopping if the block terminates), pops the scope, and -- if not already terminated -- runs `deferred_statements` in reverse then releases `owned_locals` in reverse (`releaseLocalByName`). Always removes the block's owned-local names from `current_local_types` and deinits the three scope lists. This is the core scope-end ARC release.

  - **`.if_stmt`**: Compiles the condition, compares `!= 0` to i1, drains temporaries, appends `then`/`else?`/`ifcont` blocks, conditional-branches, compiles each branch (branching to `ifcont` if it did not terminate), positions at `ifcont`.

  - **`.while_stmt`**: Appends `while_cond`/`while_body`/`while_exit`; saves and sets `current_break_bb` = exit, `current_continue_bb` = cond, `current_loop_scope_depth` = current scope count; branches to cond, compiles the condition compare, compiles the body (branch back to cond if not terminated), restores the saved loop context, positions at exit.

  - **`.break_stmt`** / **`.continue_stmt`**: If the corresponding target block is set, call `releaseScopesForLoopExit` then branch to exit/cond; else return `error.BreakOutsideLoop` / `error.ContinueOutsideLoop`.

  - **`.return_stmt`**: Compiles the value (if any), then applies the ABI wrapping in order: (1) NESTED value-optional return -- if the declared return type is a value-optional and the returned expr is not `undefined` and (does not already yield a valopt box OR the return type is nested), box it (`buildValoptBox`); the nested case handles `Map<K, int|undefined>.get()` where the key WAS found so the outer level must be a present box wrapping the inner. (2) Trait-return widening -- if the declared return type is a trait and the value resolves to a known struct, `constructTraitObject`. (3) Error-union wrap -- if the return type is an error union (`errUnionParts`), decide `is_err` by comparing the value's resolved type to the error arm, box the ok arm if it names a value-optional (the F1 fix so `catch`/`try`/`??` do not ARC-release a raw int as a pointer), run `runErrdefers()` if it is the error path, then `buildErrUnion`. Consumes the return temp, drains temporaries, bitcasts a double result to the i64 word. Then, for a plain owned r-variable return that was not wrapped/widened, retains the return value (retain-on-return-borrowed: a returned borrow must be retained so the caller owns a live reference). Runs every scope's `deferred_statements` (all scopes, innermost first, reverse within each). Calls `releaseLocalVariables()`. Emits the terminator: async → store into the promise result slot and branch to the coroutine final block; `main` → `ret` the value (or `ret 0`); else `ret` the value; else for a `_new` constructor load and return `self`, else `ret void`.

  - **`.defer_stmt`**: Appends the deferred expression to the top scope's `errdeferred_statements` (if `is_err`) or `deferred_statements`. Errors: `error.DeferOutsideScope` if the scope stack is empty.

  - **`.switch_stmt`**: Compiles the discriminant, resolves its type to the module-scoped enum name (`scopedTypeName`, the S3 collision fix). Detects a tagged union (any variant with a payload type or fields). If tagged, the discriminant word is a pointer; load the tag from `*discr` and switch on the tag. Appends `switch_default`/`switch_merge`, builds an `LLVMBuildSwitch`. For each case: appends a `switch_case` block; for a tagged union, binds payloads by loading from `union_ptr + ptr_size (+ idx*ptr_size)` into the pattern's variable allocas, retaining owned payloads (recorded in `retained_payloads` for later release) -- handles single-payload `Variant(x)`, tuple-form `Rect(w,h)`, and struct-init form `Variant{...}`. A case guard (`case v if cond`) is evaluated AFTER payload binding; on failure it releases the retained payloads and branches to `default`. Compiles the case body; if the body did not terminate, releases retained payloads and branches to `merge`. Computes each case's integer label: an enum variant's explicit value or its ordinal, or (non-enum discriminant) the integer literal with optional unary `-` (the fix so a known integer discriminant type does not leave every label at 0). Adds each `LLVMAddCase`. Finally compiles the default case and positions at `merge`. Errors: `error.VariableNotFound` for an unbound payload variable.

  - **`.for_stmt`**: Appends `for_cond`/`for_body`/`for_incr`/`for_exit`. If an iterator is present it must be a range (`for (i in a..b)`); non-range iterables and destructuring bindings are `error.UnsupportedStatement`. Allocas the loop var, stores the range start, records it in `locals` and as type `int` in `current_local_types`. Else if a C-style initializer is present, compiles it. Saves/sets the break (exit), continue (incr), and loop-depth context. Branches to cond; builds the condition (range compare `SLE`/`SLT`, else the C-style condition compare, else always-true); conditional-branches to body/exit; compiles the body (branch to incr if not terminated); the incr block increments the range var or runs the C-style increment then branches to cond; restores loop context; positions at exit.

**Gotchas / invariants.**
- The terminated-block guard at the top (and repeated after each branch) is what keeps LLVM well-formed: never emit into an already-terminated block.
- `returnIsBorrow` deliberately returns FALSE for `.ident`; the `let` copy-on-assign path treats `.ident` OR `returnIsBorrow` as a borrow precisely because of this.
- `runErrdefers` is error-path only; ordinary `return` runs `deferred_statements`, not errdefers.
- Loop exits must release inner scopes (`releaseScopesForLoopExit`) or per-iteration owned locals leak; the block handler does the normal fall-through release, the loop-exit handler does the jump-out release.
- Value-optional boxing appears in three places (`let`, `return`, error-union ok arm) with the same guard shape: skip if `undefined` literal or if the expr already yields a valopt box; the return-nested case adds the "outer present box wraps inner" exception.
- Payload retains in a `switch` are tracked in `retained_payloads` and released on every exit edge (guard-fail, non-terminating body) to stay balanced.

## `src/backend/codegen/coverage.zig` (108 lines)

**Role in the pipeline.** A small block-coverage registry used only when `coverage_enabled`. `compileStatement` calls `registerBlock` per non-std statement to obtain a stable block id (and then emits an increment), and `compile` calls `writeMetadataFile` at the end to persist the id→location table as JSON for the coverage tooling. It writes the file with raw libc `fopen`/`fwrite`/`fclose` (declared `extern`) rather than Zig's `std.fs`, so the metadata is emitted independent of the build's IO plumbing.

**Key types & data structures.**
- **`pub const CoverageBlock`**: one coverage point -- `id: usize`, `file_path: []const u8`, `line: usize`, `col: usize`, `description: []const u8`. The `file_path` and `description` are heap-duplicated and owned by the registry.
- **`pub const CoverageRegistry`**: `allocator` + `blocks: std.ArrayList(CoverageBlock)`.

**Module-level state / constants.** Three `extern fn` C bindings: `fopen`, `fclose`, `fwrite`. No mutable module state.

**Functions.**

- **`pub fn init(allocator) CoverageRegistry`**. Returns an empty registry (`blocks = .empty`). No allocation yet.

- **`pub fn deinit(self: *CoverageRegistry) void`**. Frees every block's duplicated `file_path` and `description`, then deinits the list. Owner of those dupes.

- **`pub fn registerBlock(self, file_path, line, col, description) !usize`**. De-duplicates by `(file_path, line)`: if a block with the same file and line already exists, returns its id (so the same source line is one coverage block regardless of column/description). Otherwise assigns `id = blocks.len`, dupes `file_path` and `description` (registry-owned), appends the block, and returns the id. Allocation: two `dupe`s per new block, freed in `deinit`.

- **`pub fn writeMetadataFile(self) !void`**. Opens `__nova_cov_metadata.json` for writing (`error.FileOpenFailed` if `fopen` returns null, after printing), `defer fclose`. Writes a JSON array of objects, one per block, with `id`, `file_path` (backslashes escaped), `line`, `col`, `description` (backslashes and double-quotes escaped). Small numbers are formatted into a 64-byte stack buffer via `bufPrint`; strings are written char-by-char through `fwrite` with manual escaping. Emits a trailing comma between elements and closes the array. Side effect: the metadata file on disk. Errors: `error.FileOpenFailed`, plus any `bufPrint` error.

**Gotchas.** De-duplication is by file+line only, so two coverage-relevant statements on the same physical line share one id and one counter. The manual JSON escaping only handles `\` and `"` (and `\` inside file paths); other control characters are written verbatim, which is fine for the source-location strings it stores.
