# Nova Compiler LLD: `src/backend/codegen/expressions.zig`

This is the expression lowering half of the Nova code generator. It takes a type-checked, monomorphised `ast.Expression` and emits the LLVM IR that computes its runtime value. Every Nova expression kind flows through one giant dispatcher, `compileExpressionInner`, wrapped by `compileExpression` (which adds ARC temporary tracking): literals, identifiers, binary and unary operators, function calls, method and namespaced calls, generic calls, field and index access, struct/tuple/enum/union/array/map construction, closures, optional chaining, nullish coalescing, template interpolation, JSX/NSX markup, casts, trait dispatch and downcasts, error-union construction, `try`/`catch`, `await`/`spawn`, and the value-optional (valopt) box/unbox insertion points. It also carries a large set of intrinsic lowerings that never touch a real Nova function: SIMD builtins, the `mem.*` typed load/store family, `bytes.*` raw memory accessors, decimal arithmetic, the storage/witness element ABI, and the async I/O primitives.

Every function here is a free function whose first parameter is `self: *LlvmCompiler`. They are pulled into `LlvmCompiler`'s method namespace by `usingnamespace` in `llvm_codegen.zig`, so in prose they read as methods (`self.compileExpression(...)`). This file owns no persistent module-level state of its own; all compiler state (`self.builder`, `self.func_map`, `self.structs`, `self.locals`, `self.pending_temps`, the async/coroutine cursors, the valopt suppression flag, and so on) lives on `LlvmCompiler` in `llvm_codegen.zig`.

## `src/backend/codegen/expressions.zig` (5586 lines)

### Role in the pipeline

`compileExpression` is the single entry point every other codegen file calls to turn an expression into an `LLVMValueRef`. Internally it calls `compileExpressionInner`, which is a `switch (expr.kind)` over the AST `ExpressionKind` tag. Each arm builds IR directly through the LLVM C API (`core.LLVMBuild*`) using `self.builder`, and returns the computed value.

The value ABI is uniform and word-based: almost every expression returns the **i64 value-word** (`self.val_type`, an `i64`). Integers, booleans, and enum tags are the value itself; heap objects (strings, lists, structs, closures, error-union boxes, `any` boxes) are returned as their pointer **cast to i64** (`ptrtoint`), so a Nova "pointer" is an integer that gets `inttoptr`-ed at each use. The two systematic exceptions are floats (a real LLVM `double`, bit-reinterpreted to/from the word by `coerceToSlotType`/bitcast) and value structs, whose "value" is the **i64 address of inline stack storage** rather than a heap pointer. `coerceToSlotType(v, val_type)` is the funnel that normalises any of these back into the i64 word before it is stored into a uniform slot (array element, closure arg, struct field, phi).

ARC, boxing, and coercion are inserted at three levels. (1) `compileExpression` itself registers owned construction temporaries into `self.pending_temps` so the statement boundary can release them (`drainTemporaries`); it deliberately skips borrows and scalar value structs. (2) Individual arms insert `compileRetain`/`compileRelease` when a value is aliased (assignment overwrite, field store, capture, container set, trait widening) or consumed. (3) The valopt seam (`buildValoptBox`/`buildValoptUnbox`) boxes a bare value into an `int | undefined` representation, or peels it, at every point where a value type meets an optional slot: struct-field stores, call arguments (guarded by `suppress_valopt_unbox`), binary operands, optional chaining, nullish coalescing, `catch` results, and template interpolation. Trait objects are constructed on the fly (`constructTraitObject`) wherever a concrete struct is passed/stored into a trait-typed slot, and downcast (load `struct_ptr` from the fat pointer) in the reverse direction.

The file leans on the type engine two ways: string-name predicates (`resolveExpressionTypeName`, `typeRefToString`, `isStringExpr`, `isFloatExpr`, `isDecimalExpr`) drive most branch selection, while the typed IR (`self.typed_ir` + `self.type_store`, via `typeOf`/`typeOfExprConcrete`/`symOf`/`opOf`) is consulted for the precise cases that a rendered name cannot answer: valopt inner types, array element counts and float element types, per-instantiation destructor TypeIds, and the shadow-report ownership diff.

### Functions (source order)

#### Value-struct storage and copy helpers

- **`fn buildValueStructStorage(self, size: u32) -> LLVMValueRef`** (pub) -- Allocates `size` bytes (min 8) as an `[N x i8]` **alloca** on the stack, zero-inits it (`store zeroinitializer`), and returns its address via `ptrtoint` to the i64 word. This is the value-struct analogue of a heap alloc: no ARC header, never retained/released/freed. The zero-init is load-bearing: a fresh heap struct's memory is zeroed, so the first owned-field write can `nova_release` a null (no-op) old value; a raw alloca would be garbage and SIGSEGV.
- **`fn retainValueStructOwnedFields(self, structAddr, struct_name) -> void`** (pub) -- After a value struct's bytes are byte-copied, each **owned (reference) field** is aliased by two structs, so this walks `self.structs.get(base).fields`, and for every field where `isOwnedDeclaredType` holds, loads the field pointer at its offset and `compileRetain`s it. Prevents the destination's (or source's) later field-drop from double-freeing.
- **`fn buildValueStructCopyInto(self, dst, src, size) -> LLVMValueRef`** (pub) -- memcpy `size` bytes `src`→`dst` via the runtime `nova_bytes_copy` (declared lazily into `func_map` if absent). Copies into an **existing** destination address (a container slot / inline field). Returns `dst`. Does NOT retain owned fields (callers pair it with `retainValueStructOwnedFields`).
- **`fn buildValueStructCopy(self, src, size) -> LLVMValueRef`** (pub) -- As `buildValueStructCopyInto`, but first allocates fresh stack storage (`buildValueStructStorage`) as the destination, then memcpies into it. The `let b = a` copy-on-assign path.

#### Storage / witness element ABI

- **`fn compileElemWitness(self, wn: []const u8, gc: GenericCallExpr) -> ?LLVMValueRef`** (pub) -- Lowers the typed element value-witness calls from `mem/witness.nova` (`witness.sizeOf<T>()`, `copyElem`, `dropElem`, `store`, `storeOver`, `load`, `moveElem`, `moveOut`) that let a pure-Nova `RawBuffer<T>` own its elements without the old `Storage` intrinsic. Computes `is_vs = isValueStructName(T)`, `elem_owned = ownedByName(T)` (note: `any` is treated as owned here, matching the old TypeId model, so `Map<K,any>` elements get a reference), and the slot width (`getTypeSize` for a value struct, else 8). Returns `null` on arity mismatch so the caller falls through to real dispatch. The exact per-verb ABI:
  - `sizeOf` → constant slot width.
  - `copyElem(dst, src)` → value struct: `buildValueStructCopyInto` + `retainValueStructOwnedFields`; scalar/ref: load the 8-byte slot from src, store to dst, `compileRetain` if owned. Returns 0.
  - `dropElem(addr)` → `dropElemAt`. Returns 0.
  - `store`/`storeOver(slot, value)` → value struct: (storeOver only) `dropElemAt` the old, `buildValueStructCopyInto`, `retainValueStructOwnedFields`; scalar/ref: **retain the NEW before releasing the old** (so an aliasing overwrite stays refcount-positive), then store. Returns 0.
  - `load`/`moveOut(slot)` → value struct returns the slot **address** (a borrow, the element IS its inline bytes); scalar/ref loads the word and, for `load` only when owned, `compileRetain`s it (`moveOut` takes existing ownership, no retain).
  - `moveElem(dst, src)` → raw byte/word move, no reference taken (ownership transfers, source left stale). Returns 0.
- **`fn dropElemAt(self, t, is_vs, addr) -> void`** (private) -- Releases the element at `addr`. Value struct with owned fields: call its destructor (`getOrCreateDestructor`) on the address directly. Reference element (or a value-optional name): load the pointer word and `compileRelease` with its destructor. No-op for scalars.

#### Const references

- **`fn isTrivialConstLiteral(expr) -> bool`** (private) -- True iff the initializer is a plain literal. Trivial literals inline cheaply at each reference; anything else (a call, string, allocation, array/struct literal) must be memoised so it runs once.

#### The `compileExpression` wrapper and temporary machinery

- **`fn compileExpression(self, expr) -> LLVMValueRef`** (pub) -- The public entry point. Calls `compileExpressionInner`, then consults `acquisitionDisposition(&expr)`: a `.borrowed` result returns immediately (no temp registration). An `.owned` result whose type name resolves gets registered as a pending temporary (spilled to an alloca via `spillTemp`, appended to `pending_temps` with its `expr_id`) so `drainTemporaries` releases it at the statement boundary. Value structs are special-cased: a scalar-only value struct is never registered (a drain `nova_release` would free a stack alloca → SIGBUS); an owned-field value struct is registered only when it is a **construction** (owned), never a borrow (a container get / field / variable), because dropping a borrow would release the aliased buffer element (double-free).
- **`fn spillTemp(self, val) -> LLVMValueRef`** (private) -- Allocates a zero-initialised i64 slot in the function **entry** block (so it dominates all uses), then stores `val` into it at the current point. Returns the slot. Used so a pending temp can be released even across branches.
- **`fn atomicCell(self, t_name) -> struct { bits, is_i64, size, ty }`** (pub) -- Resolves an `Atomic<T>` cell representation. Fails closed (compiler error, `exit(70)`) for anything that is not an integer or bool primitive (a non-primitive/float T used to default to i32 and corrupt memory). Returns bits/width/size and the LLVM cell type.
- **`fn guardOptionalDeref(self, obj_expr, handle, span) -> void`** (pub) -- If `obj_expr` is optional-typed, emits a null check on `handle` that, when null, calls `nova_optional_deref_fail(loc)` and `unreachable`. Leaves the builder in the ok BB. Inserted before field/index/length dereferences of an optional.
- **`fn diffTempOp(self, id, cg: OwnOp) -> void`** (private) -- Shadow-report only: compares codegen's own move/drop decision for an expr against the typed IR's `opOf`, tallying agree/disagree counters in `sema_shadow`.
- **`fn registerTemporary(self, val, type_name) -> void`** (pub) -- Manually spill + append a pending temp with an explicit type name (used by `try`/cast paths where the type is known but not the expr).
- **`fn consumeTemporary(self, val) -> void`** (pub) -- Removes a pending temp matching `val` (it was moved, not dropped), tallying a shadow move if reporting.
- **`fn diffDtorName(self, t: PendingTemp) -> void`** (private) -- Shadow-report only: compares the string type name a temp carries against the name rendered from its TypeId (both substituted and raw), tallying agree/disagree.
- **`fn drainDtor(self, t: PendingTemp) -> ?LLVMValueRef`** (private) -- Chooses the destructor for a draining temp: prefer the TypeId (per-instantiation) destructor via `typeOfInst`/`typeOf2`, else fall back to the string-name destructor.
- **`fn drainTemporaries(self, mark: usize) -> void`** (pub) -- Releases every pending temp above `mark` (the statement/scope boundary). If the current block already terminated, it only shrinks the list (unreachable code needs no release). Otherwise it loads each spilled temp and either drops a value struct's owned fields directly (`dropValueStruct`, never `nova_release` on a stack address) or `compileRelease`s a heap object, then zeroes the slot.

#### `compileExpressionInner` -- the per-kind dispatcher (lines 1762-4732)

**`fn compileExpressionInner(self, expr) -> LLVMValueRef`** (private) -- `switch (expr.kind)`:

- **`.literal`** -- `integer` → `ConstInt` (bit-reinterpreted so a full-width literal like `0xffff...` is exact). `bool`/`null`/`undefined` → 0/1 constants (null/undefined are 0). `string` → `getOrCreateStringLiteral` (interned). `array` → alloc `len*8` bytes (`compileAllocArray`, real ptr), GEP-store each element coerced to the word. `array_repeat` (`[v; n]`) → alloc `n*8`, evaluate `v` once, fill via a runtime `head`/`body`/`done` loop (LLVM lowers a constant fill to memset). `float` → `ConstReal double`. `decimal` → `getOrCreateDecimalLiteral` (interned, lazy). Unknown → error.
- **`.ident`** -- Resolution order: env capture (load through `envSlotAddr`), captured-global (walk `lambda_parents`), local (`locals`; loads with the alloca's real type, and if the slot is a value-optional and the *use* wants a bare value it unboxes via `buildValoptUnbox` unless `suppress_valopt_unbox`), constant (`compileConstRef`), else a bare function reference (`buildBareFnBox`). Error `IdentifierNotFound`.
- **`.binary`** -- Two big sub-cases:
  - **Assignment (`.assign`)**: compile RHS, consume its temp, then dispatch on the LHS kind. `ident` LHS: find the slot (env capture / captured-global / local), and if the target is an owned local, retain the RHS if it names an existing owner and release the old value (destructor preferred by TypeId); widen concrete→trait if the target is a trait; store coerced to the slot type. `field_access` LHS: resolve the field type, compute `obj_ptr + offset`; an inline value-struct field memcpies the RHS bytes in; an owned field retains the RHS-if-a-variable and releases the old; a trait field widens; a value-optional field boxes the RHS (unless it is `undefined` or already a box); then store. `index` LHS (`a[i] = v`): string element → truncate to i8 and store at `base+off`; float array → GEP-store the real element type; else GEP-store the i64 word. (Value-element semantics only, no ARC on the overwritten array slot yet.)
  - **Non-assignment**: resolve `left_type`/`right_type` names (load-bearing for `numToString`/`intOpKind`/`payloadEnumBoxWords`), and the predicates `is_string_concat`/`is_string_comparison`/`is_float_op` via `isStringExpr`/`isFloatExpr`. Compile both operands, unbox any valopt operand (unless the other side is a null/undefined literal). **Decimal**: if either operand is decimal (and the other is not a null literal) require BOTH to be decimal, then call `nova_decimal_add/sub/mul/div/mod` or `_cmp` (comparisons `icmp` the cmp result against 0). **Float** (and not a string concat): bitcast both to `double` and emit `FAdd/FSub/FMul/FDiv/FRem` or `FCmp` (`!=` is unordered `UNE`, `==` ordered `OEQ`; zext the bool). Otherwise integer/string: `add` handles string concat (mint non-string operands to strings via `numToString`, call `string_concat`, release the minted temporaries) or integer add canonicalised to `intOpKind`'s width; `sub`/`mul`/`shl` canonicalise; `div`/`mod` emit `emitIntDivGuard` then signed/unsigned `SDiv`/`UDiv`/`SRem`/`URem`; `shr` is `LShr` (unsigned, canonicalised) or `AShr`; bitwise `And`/`Or`/`Xor`. Comparisons: a **payload-carrying enum** `==`/`!=` does a fixed-width word-by-word box compare (`payloadEnumBoxWords`) OR'd with pointer identity; a **string** `==`/`!=` calls `string_eql`; otherwise integer `icmp` with signed/unsigned predicate, canonicalising unsigned operands and sign-extending width-mismatched operands, then zext.
- **`.unary`** -- `neg` (float → `FNeg` on the bitcast double; int → `0 - x`), `not` (`icmp eq 0` then zext), `bit_not` (`LLVMBuildNot`).
- **`.if_expr`** -- Standard `then`/`else`/`ifcont` diamond with a phi. Both branches are widened to the result trait if the if-expr's type is a trait (`widenBranchToTrait`), otherwise an owned branch takes ownership of its element (`takeOwnedElement`). Values coerced to the word before the phi.
- **`.call`** -- The largest arm. In order:
  1. `obj?.method(args)` optional-chaining method call → `compileOptionalMethodCall`.
  2. `field_access` callee: `simd.*` → `compileSimdCall`; `console.log/info/debug/err` (single arg) → the matching runtime log helper by static arg type (string/bool/other), returns 0; `*protocol.callDecoder` → indirect call of a decoder fn pointer with 4 args; `Storage<T>` `get`/`set` → inline slot addressing (value-struct element returns/memcpies inline bytes, reference element loads/stores an 8-byte slot with retain/release when owned); `decimal.fromInt/toInt/fromString`; `mem.xorBytes` → `nova_mem_xor`; the whole `bytes.*` raw family (`alloc`/`alloc_persistent`/`alloc_persistent_nz`/`free`/`arenaMark`/`arenaReset`/`copy`/`write_byte`/`write_i32`/`write_u16`/`read_u16`/`read_i16`/`ptr_size`/`read_ptr`/`write_ptr`/`read_byte`/`read_i32`/`write_decimal`/`read_decimal`/`read_string`); otherwise `compileMethodOrNamespacedCall`.
  3. `ident` callee: the coroutine-reactor primitives (`currentCoro`, `coroSuspend`, `coroStart`); a **struct constructor** (`isStructType`, resolving a colliding struct through the result type) -- allocates heap or inline value-struct storage, resolves the mono/base `init`/`new`, compiles args (valopt suppression + `coerceValoptArg` + trait widening), calls it, or `initDefaultContainerFields` if there is no ctor, returns the instance pointer; a **closure call** if the ident is a local/captured; otherwise a **free function call** -- resolves the callee name (sema `legacy_mangled` preferred, else `resolveCalleeName`), rebuilds a mono name from solved type args if the base is unemitted, handles an **FFI extern** specially (string args → `nova_ffi_to_cstr`, freed after; string return → `nova_ffi_from_cstr`), compiles args with valopt/trait handling, and either `buildDriveAsyncCall` (async) or `buildCallWithCasts`.
  4. Any other callee → compile it and `buildClosureCall`.
- **`.generic_call`** -- Also large. In order: `witness.<fn><T>` value-witness (`compileElemWitness`); `field_access` callee sub-cases -- HTTP verb routing (`app.get<T>(...)` → synthesised `__addRoute`), `Atomic` cell construction, `json/yaml.parse<T>` (reifying the target type-param via the TypeId overlay) → `compileGenericParse`, `mem.<op><T>` → `compileMemCall`, the `serde.*` family (`bind`/`dump`/`planFor`/`bindRow`/`bindAll`/`bindWire` each resolving `T__<verb>` and trapping in an erased generic body, `typeName` → string literal), `protocol.callDecoder`, `NovaConnection.query/queryStruct<T>` → `compileNovaQuery`, `Atomic.new`, `bytes.new_persistent`/`new_with_allocator` (the latter branching on allocator kind), then `compileExplicitGenericMethodCall`, a `Type<...>()` generic-struct constructor, a namespaced generic spec (`findNamespacedSpec`), and finally `compileMethodOrNamespacedCall`; `ident` callee sub-cases -- colliding-struct resolution, `Atomic`, `Storage<T>` (sized by element slot width), a generic-struct constructor (build `Name_T_...` gen name, resolve mono/base `init`/`new`, else `initDefaultContainerFields`), a closure call, else a generic **free function** call (rebuild `base__T...` spec name, `buildDriveAsyncCall` if async else `buildCallWithCasts`). Unknown target → error.
- **`.struct_init`** -- Three shapes: an **enum variant** with payload (`findEnumByVariant`) → alloc `tag + max payload`, store the tag at word 0 and each named payload field at `8 + idx*8` (taking ownership of owned payloads); a **union** → alloc max size, store each field at offset 0 in its own LLVM type; a **struct** → alloc heap (or inline value-struct storage), and for each field: compile the value, widen concrete→trait (consuming temps, releasing the struct), take ownership of an owned field, box a value-optional field (unless undefined/already-boxed), then either memcpy an inline value-struct field or store the coerced value. Returns the instance pointer.
- **`.field_access`** -- First the non-`.field` interpretations: an **enum member** (`Enum.Variant`, scoped by file) -- a tagged enum allocates a tag-only box, a plain enum returns the constant tag/value; a module-scoped **const**; a module-qualified **function reference** (`mod.fn` → shortest `_<mod_fn>` suffix match → `buildBareFnBox`); `.length`/`.len` (fixed array → constant element count from typed IR; string/heap → load the i32 header length at `ptr-4`, zext); the error-union projections `.ok`/`.error`/`.value` for non-struct receivers (constant 1/0, or the value itself). Then the real **field load**: compile the object, `guardOptionalDeref`, resolve the field type, compute `obj_ptr + offset`; an inline value-struct field returns the **address** (a value struct's value is its address); otherwise `inttoptr` to the field type, load, and `castToValType`.
- **`.closure`** -- Look up the lifted lambda function (by instantiation-scoped closure key, falling back to the base key), get its ptr word (`fnRefInt`). Build the capture env (persistent alloc of `caps*8`, storing each captured variable's value, retaining owned ones), the cleanup thunk (`buildClosureCleanup`), and the 3-slot closure box `{fn_ptr, env, cleanup}` (persistent alloc). Returns the box word.
- **`.index`** -- Compile the object, `guardOptionalDeref`, compile the index. String → load i8 at `obj+off`, zext. Array → GEP the base ptr (float array loads the real element type; else the i64 word).
- **`.tuple`** -- Alloc `len*8`, store each element at `idx*8`, widening a trait element (`tupleElemTraitName`, consuming temps + releasing the struct) or taking ownership of an owned element. Returns the tuple pointer.
- **`.try_expr`** -- Load the error-union box's tag word; if it is 1 (err), run errdefers and **early-return the box**: inside an async fn this means storing the box into the promise result slot and branching to the final suspend (NOT a raw `ret`, which would corrupt the coroutine state machine), else a plain `ret`. In the ok BB, load the payload at `box+8`; if the ok part is owned, retain it and register it as a temporary. Returns the payload.
- **`.catch_expr`** -- Load the box tag; branch `err`/`ok`/`done` with a result slot. In the err BB, if `err_name` binds, materialise (or reuse) an entry-block alloca local for the error, record its type, retain the err payload if owned, store it, then compile the handler (boxing it if the ok type is a value-optional and the handler is neither undefined nor already-boxed). In the ok BB, load the payload (retain if owned). Merge to a phi. Consumes the handler temp.
- **`.optional_chaining`** (`obj?.field`) -- Evaluate the object once (unbox if it is a valopt box), branch present/null; in present, load the field (value-struct-inline returns the address, else load+cast), box the result if the whole expr type is a value-optional; phi 0 for the null arm.
- **`.nullish_coalesce`** (`a ?? b`) -- Evaluate the left (unbox if valopt). The key subtlety is a **nested value-optional peel** (`g ?? d` where `g : (int|undefined)|undefined`): the present arm co-owns the container's inner box, so it retains on a dedicated `present` BB and boxes the RHS default so both phi arms share the inner box representation. Otherwise standard: RHS in its own BB (widened concrete→trait if the left is a trait), phi of `left_present`/`rhs`; for the non-valopt case, retain/consume the left and right temporaries according to ownership.
- **`.jsx_element`** -- `compileJsxElement`.
- **`.block_expr`** -- Pushes a scope, compiles each statement until the block terminates, runs the scope's deferred statements in reverse, pops the scope. Returns 0. (A block expression yields no value.)
- **`.template_expr`** -- Fast path: a single `${x}` interpolation with no surrounding text and a prim/decimal type returns a fresh owned string directly (`numToStringT` / `nova_decimal_to_string`), avoiding a StringBuilder round-trip (strings deliberately fall through to the safe path). General path: alloc + init a `StringBuilder`, set `current_string_builder`, append each part (`compileAppendToStringBuilder` for interpolations, recursing block-expr parts), `toString`, `delete`, release the builder struct, return the final string.
- **`.cast`** (`x as T`) -- Reading out of `any` unboxes the `{payload, dtor}` box and retains if the target is heap-owned. A trait→concrete downcast checks the runtime vtable against the target's expected vtable and **traps on mismatch** (invalid downcast), then loads and retains `struct_ptr`. Numeric casts (native only): float→int is `bitcast`+`FPToSI` (then width-narrows); int→float is `SIToFP`+bitcast; a narrowing integer cast truncates to the target width and re-extends by signedness (previously a silent no-op that kept the wide value).
- **`.await_expr`** → `buildAwait`; **`.go_expr`** → `buildGo(..., false)`.
- **`else`** → error `UnsupportedExpression`.

#### Integer-op helpers (post-dispatcher)

- **`fn isFloatTypeName(n) -> bool`** (private) -- `f64`/`double`/`f32`/`float`.
- **`fn intOpKind(left_name, right_name) -> ?IntOpKind`** (private) -- The result width/signedness for an integer binop: the wider operand wins; on a tie the result is signed only if both are signed. Non-integer operands contribute null. Inline `kindOf` maps a type name via `types_mod.cgPrim`.
- **`fn isWideIntTypeName(n) -> bool`** (private) -- `long`/`ulong`/`i64`/`u64` (64-bit).
- **`fn emitTrapIf(self, cond, msg) -> void`** (pub) -- Inline `if (cond) nova_panic_cstr(msg); unreachable;`, leaving the builder in the continuation BB. The primitive behind every runtime trap here.
- **`fn emitIntDivGuard(self, l_val, r_val, signed, width, zero_msg, ovf_msg) -> void`** (pub) -- Traps on divide/modulo by zero always, and on `INT_MIN / -1` overflow for signed 64-bit ops (narrower signed ops run at the i64 word and wrap on canonicalise, so they cannot overflow the machine op).
- **`fn canonicalizeInt(self, val, width, signed) -> LLVMValueRef`** (pub) -- Truncates the i64 word to `width` and sign/zero-extends back, so a sub-64-bit integer op produces the correctly-wrapped value in the word. No-op for width ≥ 64.
- **`fn numToStringImpl(self, val, is_float, is_bool) -> LLVMValueRef`** (pub) -- Calls `nova_f64_to_string` (bitcasting the word to double), `nova_bool_to_string`, or `nova_i64_to_string`.
- **`fn numToString(self, val, type_name) -> LLVMValueRef`** (pub) -- `numToStringImpl` keyed by a rendered type name.
- **`fn numToStringT(self, val, tid) -> ?LLVMValueRef`** (pub) -- `numToStringImpl` keyed by a TypeId's prim kind (float/bool/int; void and non-prim → null).

#### Optional method call, string-builder append, JSX

- **`fn compileOptionalMethodCall(self, call, expr_ptr) -> ?LLVMValueRef`** (pub) -- Lowers `obj?.method(args)`. Resolves the receiver's inner (non-optional) type from the typed IR to the owning struct and the method fn (`Struct_method`, then lowercased). Evaluates the receiver once, branches present/null; in present, calls the method with the receiver as leading `self`, and boxes the result if the whole expr is a value-optional; phi 0 for null. Returns null (falls through) if the type or method cannot be resolved.
- **`fn compileAppendToStringBuilder(self, sb_val, val, expr_type_opt, opt_part) -> void`** (pub) -- Appends `val` to a `StringBuilder`, choosing by the typed IR when `opt_part` is present: `string` appends directly; `prim` converts via `numToStringT` and releases the temp; `decimal` via `nova_decimal_to_string`; `optional` emits a present/absent diamond that prints the unboxed inner value (or the heap-optional string pointer) when present and the literal `"undefined"` when absent. Falls back to the string-name path (`string` direct; primitive → `numToString` + release) then a plain append.
- **`fn jsxAppendVal(self, sb, val) -> void`** (pub) -- Append an already-string value (append copies + borrows, so no retain).
- **`fn jsxAppendLiteral(self, sb, text) -> void`** (pub) -- Accumulate static text into `jsx_pending_literal` (coalesced, emitted at the next flush).
- **`fn jsxFlushLiteral(self, sb) -> void`** (pub) -- Emit the accumulated static run as ONE append, then clear.
- **`fn jsxAppendExpr(self, sb, expr) -> void`** (pub) -- Flush the preceding static run, then append an interpolated `{expr}` child: a `string` is **HTML-escaped into the builder** (`web_response_escapeHtmlInto`, XSS-safe by default); a borrowed `Str` value struct escapes straight from the view (`web_response_escapeHtmlIntoView`, passed by value, NOT coerced); a primitive goes through `numToString` + release; else a plain append.
- **`fn emitJsxInto(self, sb_val, jsx) -> void`** (pub) -- Renders a whole element tree into ONE builder (the render-throughput fix): sets `current_string_builder`, appends `<tag`, each attribute (`name="..."` with literal or interpolated value), then either `/>` (no children) or `>`, the children (text → literal, nested element → recurse into the SAME builder, expression → `jsxAppendExpr`, statement `{for}`/`{if}` → flush then `compileStatement` which appends into the same builder), and `</tag>`.
- **`fn compileJsxElement(self, jsx) -> LLVMValueRef`** (pub) -- The expression entry: alloc + init one `StringBuilder`, `emitJsxInto`, flush the trailing static run, `toString`, `delete` (frees the internal buffer), release the builder struct, return the final string.

### Gotchas, invariants, footguns

- **The i64-word ABI is pervasive.** Values are the i64 word; heap objects are `ptrtoint` pointers; floats are bit-reinterpreted doubles; value structs are the i64 **address of stack storage**. Always route through `coerceToSlotType` before storing into a uniform slot, and `inttoptr` before dereferencing. A `double` argument compiles to a real `double`, so it MUST be coerced to the word before an all-i64 call/closure type or the call signature mismatches.
- **Addresses must stay 64-bit.** Address arithmetic uses the i64 word (`buildAdd` on the word, then `inttoptr`); the "int is 32-bit" trap from the codebase applies -- never let an address flow through a 32-bit path.
- **Value structs are never ARC-freed.** `buildValueStructStorage` is a stack alloca with no header; a drain `nova_release` on it is a SIGBUS. `compileExpression` only registers an **owned-field construction** value struct as a temp (dropped via `dropValueStruct`), never a scalar-only one and never a **borrow** (container get / field / variable) -- dropping a borrow releases the aliased buffer element (double-free). Inline value-struct fields are memcpied, and their field read returns the **address**, not a loaded pointer.
- **Valopt-zero traps.** `undefined`/`null`/absent is the integer 0, and a value-optional boxes a value (0 == undefined). Every point where a value type meets an optional slot must box (`buildValoptBox`) unless the source is an `undefined` literal or already a box (`exprYieldsValoptBox`), and every consuming point must unbox -- but `suppress_valopt_unbox` is set while compiling an argument bound to a valopt parameter, so the box is passed through intact. Missing a box makes a raw int (e.g. `999`) reach a consuming `?? d`, which unboxes it as a pointer → SEGV. The **nested** valopt peel in `nullish_coalesce` additionally co-owns the container's inner box (retain on the present path only) and boxes the RHS default so both phi arms share the inner representation.
- **Borrow vs own.** `acquisitionDisposition` decides temp registration; `namesExistingOwner` + `isOwnedExpr` decide whether a value already has an owner (retain) or is a fresh temp (consume). An assignment/field-store retains the RHS only when it names an existing owner, and releases the old slot value. A trait widening always releases the original struct after constructing the fat pointer.
- **Trait fat pointers.** Passing a concrete struct into a trait slot constructs a fat pointer (`constructTraitObject`); passing a trait object into a concrete slot **downcasts** by loading `struct_ptr` from the fat pointer (borrow, no retain) -- skipping this passes the fat pointer AS the struct and runs a mismatched destructor (silent UAF). `x as Concrete` traps on a vtable mismatch.
- **Async early-return through the coroutine.** Inside an async fn, a propagating `try` (and any early exit) must store into the promise result slot and branch to the final suspend BB, never a raw `ret` -- a raw `ret` bypasses the coroutine state machine and corrupts it (the error box is mistaken for a handle) → crash on resume.
- **`spawn` must be a direct async call.** `awaitedCallHandle`/`buildGo` only accept a direct async fn call; a spawned coroutine that widens trait args must hold them alive across the boundary (`nova_coro_hold_arg`), since the caller's temporaries drain before the coroutine runs. A generic async call must resolve to the per-instantiation spec, not the erased base body (which traps at runtime).
- **`serde.*` in an erased generic body traps rather than failing the build** -- the erased body never runs (real calls route to the concrete spec), so a missing `T__bind`/`planFor`/... on an unresolved type-param emits `emitTrapIf(true, ...)` and returns 0; a genuinely-missing binder for a KNOWN struct still hard-errors.
- **`getFunc`/module-qualified lookup are deterministic by shortest `_`-bounded suffix.** A first-hashmap-hit lookup was order-dependent and silently flipped `url.parse` to `url.test_url_parse` when modules were added.
- **`compileConstRef` uses `compileExpressionInner` (not `compileExpression`)** for the init, and `internal` per-object linkage, so the moved-into-global value is not tracked as a statement temporary and the cache does not clash at link across the T6 per-file object split.
- **Div/mod always guard**; unsigned comparisons canonicalise operands first; width-mismatched integer comparisons sign-extend the narrower side.
